# Legacy

Material from the 2023 thesis, preserved as submitted and produced by no code in
this repository. Nothing here is regenerated by the pipeline and nothing here is
an output of the reproduction.

`data/` holds the nine source JPGs the thesis figures were built from, and
`figures/` the ArcGIS exports that appear in the document. `output/` holds what
the 2023 notebook wrote. Each has its own README recording provenance.

`Duyst-Yale-Thesis.md` is a markdown rendering of the thesis, and it is **not**
the document of record. `writeup/Duyst_Thesis.pdf` is. The two are not the same
document: the markdown numbers its figures sequentially, Figure 1 through 18,
where the PDF uses the chapter-decimal scheme the text actually refers to, so a
figure number does not carry between them. It embeds its own eighteen images as
base64 data URIs rather than referencing the committed figures, so its pictures
are not necessarily this repository's pictures. And it has no abstract, results
or discussion section at all. notes/decisions.md sets out the argument in full.

It lives here rather than at the repository root for two reasons. Its status is
then obvious from its location, which it was not when it sat immediately above
`Duyst_Thesis_Final.ipynb` in the root listing. And at 6,625,368 bytes it
exceeds the size GitHub will display, so clicking it in the web interface
returns a size refusal rather than the thesis; a reader who wants the text
should open the PDF, and a reader who wants this file should clone or download
it raw.
